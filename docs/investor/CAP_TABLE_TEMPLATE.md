## Rules for using this template

- A row may only be added once a real, signed instrument (share allotment, SAFE, founder
  agreement) exists.
- Percentages must always sum to 100% across all real rows once any are added — do not
  publish a partial table that implies unallocated equity is unaccounted for.
- This document is not a substitute for a company's official register of members / cap table
  management tool once incorporation and share issuance occur.
